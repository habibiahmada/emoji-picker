# Google Antigravity

- Workspace rules live in `.agent/rules/` (supported; Antigravity also accepts `.agents/rules/`).
- Root `AGENTS.md` / `GEMINI.md`-style context: use root `AGENTS.md` pointing at `.agent/`.
- Graphify: `graphify install --platform antigravity`.

Do not fork a second copy of rules under `.agents/` unless Antigravity on this machine
stops reading `.agent/rules/` — prefer one folder.
